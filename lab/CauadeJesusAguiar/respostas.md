1. O problema computacional é o desafio a ser resolvido, o algoritmo é a lógica e o código-fonte é a implementação em uma linguagem.
2. O compilador javac transforma o arquivo em bytecode, enquanto a JVM traduz esse bytecode para código de máquina e o executa.
3. O método main serve como a porta de entrada obrigatória para iniciar a execução de qualquer aplicação Java.
4. A ordem correta do fluxo é: arquivo .java, javac, arquivo .class, JVM e programa em execução.
5. Declarar uma variável define seu tipo e nome, enquanto inicializar consiste em atribuir o seu primeiro valor.
6. É de tipagem forte porque exige a definição do tipo de cada variável, proibindo mudanças posteriores ou misturas incompatíveis sem conversão.
